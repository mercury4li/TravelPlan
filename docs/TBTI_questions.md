# TBTI 题库（全量情景题）

本文档为 **产品与运营可读稿**，与程序读取的数据文件 `**[web/tbti/src/data/questions.json](../web/tbti/src/data/questions.json)`** 内容应对齐；若改版题库，请 **先改本文档或与其同步更新 JSON**，避免文案与线上脱节。

维度说明与分型算法见 `**[docs/TBTI_scoring.md](TBTI_scoring.md)`**；命名与十八型文案出处见 `**[docs/TBTI.md](TBTI.md)**`。

---

## 体量与规则摘要


| 项    | 约定                                                       |
| ---- | -------------------------------------------------------- |
| 题量   | 20 题（单选）                                                 |
| 选项   | 每题 4 项（`a`–`d`）                                          |
| 赋分   | 每项含四维整数增量 `delta`：`xing`（行）、`qian`（钱）、`xian`（险）、`ren`（人） |
| 叙事要求 | 具体旅程行为，避免抽象自我评价（与 `TBTI.md` §5 一致）                       |


**delta 含义**：答题后按轴累加 raw 分，再按本题库可达区间归一化到 `[-1, 1]`（详见评分文档）。
