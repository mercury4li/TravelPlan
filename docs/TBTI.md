# 旅格测试（TBTI）

**Travel Behavior Type Indicator**

本文档整理「旅格测试」的命名、维度、18 型代号与传播用语，供产品与内容统一引用。

---

## 1. 产品命名


| 层级    | 名称         | 说明                                                             |
| ----- | ---------- | -------------------------------------------------------------- |
| 中文名   | **旅格测试**   | 「旅格」对应「人格」，易记、适合做话题（如 `#旅格测试`）。                                |
| 英文名   | **TBTI**   | Travel Behavior Type Indicator，与 MBTI / SBTI 同属「全称 + 四字母缩写」体系。 |
| 副标题建议 | 你在旅途里是哪种人？ | 首次曝光时降低认知成本；可与中文名并列展示。                                         |


**组合对外话术**：旅格测试 TBTI｜Travel Behavior Type Indicator

**命名要点**

- **Behavior**：强调订票、路线、预算、冲突、拍照等**可观察行为**，与「旅行场景」强绑定。
- 字母缩写与 MBTI 相近，传播时可刻意区分全称，避免误扫成通用人格测试。

---

## 2. 定位与免责声明

- **定位**：基于旅行中的偏好、决策与习惯的趣味分型工具，用于自我觉察与社交分享。
- **非临床**：不构成心理学诊断；不可替代专业评估。
- **灵感参考**：分型逻辑可参考网络化人格体系（如多维度行为标签、易传播的代号），但 **TBTI 题型、维度与 18 型均为本文档独立设定**，与第三方商标或题库无隶属关系。

---

## 3. 四条旅行维度（底色）

测评可通过题目在四轴上打分，再映射主导气质得到主型；亦可输出「主型 + 副型」或四轴条形图，避免「一次定终身」。


| 轴     | 左极               | 右极          |
| ----- | ---------------- | ----------- |
| **行** | 攻略卷王（行程细到分钟）     | 说走就走（路上再订）  |
| **钱** | 算账大师（券、里程、平替）    | 体验至上（来都来了）  |
| **险** | 风险雷达（Plan B/C/D） | 冒险体质（先试试再说） |
| **人** | 社交发动机（群聊、拼车、组队）  | 独狼模式（独处充电）  |

## 5. 三件套传播文案（与 `web/tbti/src/data/types.json` 对齐）

每型固定 3 份文案，对应不同传播场景：

- **hook**：海报 / 结果首屏大字，10–18 字，必有反差。
- **selfRoast**：详情段落自嘲，2–3 句，「画面 + 反转」公式。
- **calloutCp**：@ 队友 / 朋友圈传播句，制造「被认领」钩子。

## 6. 题型与结果呈现建议（结果页信息架构）

**出题**

- 尽量问**具体行为**（例如：延误 4 小时先打开游戏 / 改签 App / 群聊吐槽 / 睡觉），少问抽象自我评价。
- 选项贴近真实旅程场景，便于用户代入。

**结果页采用 SBTI 风格的 Hero + 章节化布局**，由 `web/tbti/src/lib/persona.ts` 生成；18 型在新架构里是「最像的旅格代号」，不再是诊断结论。


| 区块            | 角色    | 内容                                                  | 生成规则                                                                                                      |
| ------------- | ----- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Hero**      | 主视觉   | 居中大字：型代号（如「先冲为敬」）+ 短码（SEND-IT，accent 色）+ 一句 hook 引文 | 18 型最近邻匹配；hook 来自 `types.json`                                                                            |
| **旅行人格描述**    | 立体化叙述 | 基础句（16 象限 / 中庸特例）+ 主导轴亮点修饰句 + 与主型偏差风味提示             | 四维符号 → `QUADRANT_PERSONAS[Quadrant]`；主导轴 |v|≥0.5 时追加 `AXIS_HIGHLIGHTS`；与主型指纹差 ≥0.35 时由 `getFlavorNote` 生成 |
| **维度画像**      | 事实可视化 | 四轴条形图 + 每根轴下方一句 **5 档 verdict**                     | 每轴值落入 `farLeft / left / mid / right / farRight`（阈值 ±0.6 / ±0.2），从 `AXIS_VERDICTS` 取词                      |
| **和你出门是什么体验** | 梗与传播  | 主型 selfRoast 段 + @队友 callout 块 + 边界提示               | 取 `types.json` 中该型 `selfRoast` / `calloutCp`；当与第二接近型距离差 < `BORDERLINE_GAP` 显示「与 XX 接近」                    |
| **操作区**       | 二次行动  | 复制全文 / 再测一次                                         | 复制内容由 `buildShareText` 拼装，Hero + 人格描述 + 四轴 + @队友 + 标签                                                     |


**为什么这套架构画像不扁**

- 维度画像 / 旅行人格描述完全由用户得分驱动，不依赖型指纹——任何一根轴有方向，画像就有方向，**天然立体**。
- 18 型只在 Hero 区出现，扁不扁不影响人格描述。
- 因此 type fingerprint 保持当前 `types.json` 即可，无需为「立体化」重塑指纹。

**立体化人格描述的两段式**

```
基础句：    16 象限组合中的一段（约 50 字）
亮点修饰：  当某根轴 |v|≥0.5 时追加，强调「主导特质」（约 15 字）
```

例：用户得分 `行 +0.62 / 钱 −0.55 / 险 +0.30 / 人 −0.45` →

- 基础句：「说走就走的省钱团长——今晚定明早飞，机票券能薅就薅，群友是行程的共同参与者，下一站靠投票。」
- 亮点：「行动力是你最大的底气。」

**复制全文样例**

```
【我的旅格人格 · 先冲为敬（SEND-IT）】
票买完才想起来没假。

说走就走的省钱团长——今晚定明早飞，机票券能薅就薅，群友是行程的共同参与者，下一站靠投票。行动力是你最大的底气。

行 +0.62  说走就走选手，落地再说
钱 −0.55  偏算账，能省则省
险 +0.30  偏冒险，先试试再说
人 −0.45  偏社交，喜欢有同行人

@ 队友：和先冲为敬出门，行程基本不超过 24 小时构思。
你比典型的「先冲为敬」更抠、更社交。

#旅格测试 #TBTI
```

## 7. 传播话术示例（可直接使用）

**自嘲三连**（主型 × 副型 × 第三接近型，由前端动态拼）

> 我是 比价CPU × 坏事编剧 × 都行挂件，谁懂啊。

**@ 队友**（取主型 calloutCp）

> 行走 ATM 的朋友，整趟旅行体验全靠 TA 兜底。

**话题标签（示例）**

- `#旅格测试`
- `#TBTI`
- `#旅行人格灵魂关机`
- `#全队妈咪在线带娃`
- `#先冲为敬后悔套餐`

**口诀（可选用于海报 / 短视频）**

路书精画线，队长瘾拍板，先冲为敬先干；比价CPU算清，坏事编剧心慌，都行挂件看淡；瞎溜达王乱逛，九宫格命出片，天黑开机变脸；一人成团自清，灵魂关机省电，网红过敏拆爆款；铁腿特种兵暴走，反复横跳乱改，一键换皮肤换人格。
